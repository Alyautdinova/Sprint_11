# Sprint_11 — API-тесты для сервиса объявлений

Проект содержит автоматизированные API-тесты для сервиса [QA Desk](https://qa-desk.education-services.ru/). Тесты написаны на Python с использованием библиотеки `requests`, `pytest` и `requests-toolbelt`.

## 🛠 Стек технологий

*   **Python 3.x**
*   **Pytest** — фреймворк для написания тестов.
*   **Requests** — библиотека для отправки HTTP-запросов.
*   **Requests-toolbelt** — для работы с `multipart/form-data` (MultipartEncoder).
*   **Faker** — для генерации уникальных тестовых данных.
*   **Allure** — для генерации наглядных отчетов.

## 🧪 Что проверяется (Покрытие API)

В рамках проекта протестированы следующие эндпоинты:

### 1. Создание пользователя и логин
*   Создание пользователя с валидными данными и невалидными данными.
*   Логин.

### 2. Создание объявления
*   Создание объявления с валидными данными.

### 3. Редактирование объявления
*   Успешное редактирование любого поля объявления.
*   Проверка, что нельзя редактировать объявление, созданное другим пользователем.

### 4. Удаление объявления
*   Успешное удаление объявления.


## Запуск тестов с Allure

```bash
# 1. Запустить тесты с сохранением результатов
pytest --alluredir=target/allure-results --clean-alluredir

# 2. Сгенерировать HTML-отчёт
allure generate target/allure-results -o target/allure-report --clean

# 3. Открыть отчёт локально
allure open target/allure-report
```
